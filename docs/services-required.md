# Services Required

1. **Azure Traffic Manager** — DNS-based traffic routing and endpoint failover.
2. **Azure App Service** — Hosts the web application in two regions.
3. **Azure Resource Group** — Organizes and manages Azure resources.
4. **Azure Monitor** — Helps observe application availability and performance.
5. **GitHub** — Stores application source code, architecture and documentation.

Optional: Application Insights for application-level monitoring.
